# Describe Image — Activity 08.04

Verified 2026-10-24 against Pearson's current PTE Academic [Speaking and Writing format page](https://www.pearsonpte.com/pte-academic/test-format/speaking-writing/) and [Test Taker Score Guide](https://www.pearsonpte.com/ctf-assets/yqwtwibiobs4/5Sz9Ur4qbus8AEOQdetkAj/1019252a8e0a2ea4456772496a8a8c1c/pte-academic-score-guide-test-taker-2024-v3.pdf). Describe Image assesses Speaking, provides 25 seconds to prepare and a 40-second response window, permits one recording, awards partial credit, and lists Content, Pronunciation and Oral Fluency. Pearson advises focusing on the image's main information and related details.

The exercise uses four original local illustrations: a grouped cycling chart, regional density map, campus rainwater process and illustrated campus streetscape. Editable SVG source is in `content/artwork/describe-image/`; learner JPEGs are under `public/images/describe-image/`. Authored alt text describes the visual accessibly without exposing the complete scoring feature list.

The question starts only when the learner presses **Start question**; this gives the 25-second practice countdown a deliberate start point. The image remains visible through preparation, recording and feedback. Notes are transient and excluded from attempts and scoring. The response allows manual stop and is capped at 40 seconds. Speech transcription and waveform analysis must complete locally before save.

Feature coverage uses a shared deterministic lexical matcher over authored key features. It normalizes Unicode, case and punctuation, deduplicates terms, ignores a small stop-word list, and aliases common number words from zero through twenty to digits. Each feature requires at least two meaningful anchors and at least 60% of its anchors. This is keyword evidence only: it does not inspect the image, understand semantic paraphrases, or reproduce Pearson Content scoring. Optional keyword coverage is secondary. `Attempt.score` is feature coverage normalized to 0–1; no pronunciation score is inferred from Whisper. Pause, latency, speech ratio and speech rate are local diagnostics, not Pearson Oral Fluency scores.

Missed authored features produce up to four omission errors and three review items. The session summary aggregates feature coverage and local fluency diagnostics. Quick Practice remains restricted to WFD, RS and RA. IndexedDB remains v3 and the content schema remains v2.

Image integrity checks enforce a safe local `/images/` path, regular file, 20 MiB maximum, supported PNG/JPEG/WebP extension and MIME, file signature, SHA-256, exact byte count, successful single-stream image decode, declared dimensions, maximum side of 16,384 pixels and a 40-megapixel area cap. Content build and generated-bank verification validate all three supported formats with the host decoder. Package staging decodes the referenced learner assets using its restricted native FFmpeg; the original illustrations are packaged as JPEG so the app does not need an added zlib runtime library. Package FFmpeg is built with only the still-image demuxer and JPEG/WebP decoders alongside its existing media capabilities.

Validation on 2026-10-24: 28-item content build and image/audio verification passed; all 1,119 application/runtime tests passed; production build, lint and all 7 package tests passed. The Describe Image browser flow passed on Linux Chrome 154 with zero page errors and zero unexpected remote requests, including standalone, Task Practice, Mixed Practice and summary. The Linux package was built and launched offline; its standalone/session routes and JPEG hash/byte count passed, as did local Whisper transcription, shutdown cleanup and relaunch smoke. This is host package evidence, not clean-machine certification.

Known limits: lexical feature coverage is not semantic image understanding; Pearson Content, Pronunciation and Oral Fluency scores are not reproduced; no computer vision or external scoring API is used. Human learner benchmarking and physical microphone certification remain Activity 05 gates.
